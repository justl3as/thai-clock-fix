# Product

## Register

product

## Users

Thai-speaking Android users configuring the owner user's SystemUI date/time through Shizuku.

## Product Purpose

Set one of two fixed SystemUI locales and 24-hour time. Show measured setting results separately from the app's own formatting preview.

## Brand Personality

Direct, calm, precise. Retain the existing Material 3 Expressive theme and controls.

## Anti-references

Simulated success, a static clock presented as live, or a preview presented as evidence of the device's status-bar rendering. These are the specific patterns the user asked to correct.

## Design Principles

- State only what command results and readback establish.
- Label previews as previews, including when settings match.
- Require both matching locale and confirmed 24-hour setting before disabling Apply.
- Preserve the existing layout, palette and fixed owner-user scope.

## Accessibility & Inclusion

Preserve Compose accessibility semantics and explicit Thai labels. Keep preview and verification messages readable in the existing Material theme; do not use color alone to communicate verification.
